# MakaTools downloads

MakaTools is a private, offline PDF toolkit for macOS. Your files never leave your Mac: no account, no cloud, no tracking.

- Website: https://www.makatools.dev/
- Download: [latest release](https://github.com/bydamiano/makatools-site/releases/latest) (`MakaTools-<version>-arm64.dmg`, Apple Silicon)

## Install

1. Open the DMG and drag **MakaTools** onto **Applications**.
2. The app is not signed by Apple. The first time, right-click MakaTools in Applications and choose **Open**, or go to **System Settings → Privacy & Security** and press **Open Anyway**.
